# 🏕️ SafeCamp

SafeCamp is a smart safety and emergency management platform designed to enhance security, awareness, and emergency response in camping environments and outdoor activities. The system helps users stay informed, connected, and prepared through technology-driven safety solutions.

---

## 📌 Overview

Outdoor adventures are exciting, but they also come with risks such as getting lost, medical emergencies, weather hazards, and communication challenges. SafeCamp aims to provide a comprehensive platform that improves safety and preparedness for campers, hikers, and outdoor enthusiasts.

---

## ✨ Features

- 🛡️ Safety-focused platform
- 📍 Location and activity monitoring
- 🚨 Emergency alert functionality
- 🌦️ Environmental and hazard awareness
- 👥 User-friendly interface

- ⚡ Real-time information access

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/AdarshM25/SafeCamp.git
cd SafeCamp
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```

### Open in Browser

```text
http://localhost:5000
```

## 🚀 How It Works

1. Users register and access the platform.
2. Camp and trip information is recorded.
3. The system monitors safety-related information.
4. Emergency alerts can be generated when needed.
5. Users receive important updates and notifications.
